Програмне забезпечення для ресторанів та кафе.
### Опис 
Даний проєкт створений для того щоб автоматизувати основні системи в ресторанах. 

Воно оптимізує такі системи як бегункі(на кухню та бар),столи кожний має номер та у кожного офіціанта своя картка в системі.Це основні системи які присутні в програмі але е ще багато біль менших функций.
### Основна ідея 

* Полегшення праці в закладі,оптимизация великої кількості процесів.

* Зручніший процес знаходження помилок в праці заклада та офіціантів.
  
* Збільшення комфорта для гостів в закладі новими функциями 
### Головні можливості 

* Управління замовленнями: прийняття замовлення у гостя та відриттся чека в системі для відправлення бегунків.
  
* Система фіскалізуе кожен чек та відправляе в нологову та мае систему акцизи для алкоголю.
  
* Система зручної оплати Expirenza (by mono) в якої автоматична фіскалізация та відправлення чайових офиціанту.
  
* Система знижок та ваучери за якими можливо отримати знижки або сезонні знижки на різні пропозиції.
